
| Function         | Shortcut | isSelected | Description                                     |
| ---------------- | -------- | ---------- | ----------------------------------------------- |
| Create Entry     | Ctrl + N | None       | Request focus in window for input field         |
| Create Sub-Entry | Ctrl + N | Entry      | Creates a sub-entry inside an entry             |
| Edit Entry/Sub   | Ctrl + E | Entry/Sub  | Edit already created entries/sub-entries        |
| Delete Entry/Sub | Ctrl + D | Entry/Sub  | Delete an entry/sub-entry                       |
| Move Up          | Ctrl + ↑ | Entry/Sub  | Move an entry/sub-entry up                      |
| Move Down        | Ctrl + ↓ | Entry/Sub  | Move an entry/sub-entry down                    |
| Find             | Ctrl + F | None       | Request focus in window for search bar          |
| Deselect         | Esc      | Entry/Sub  | Deselects a selected entry/sub-entry            |
| Change Selection | ↑ or ↓   | Entry/Sub  | Moves from one selected Entry/Sub to another    |
| Undo             | Ctrl + Z | None       | Undo last change                                |
| Copy             | Ctrl + C | Entry      | Copies an entry and all its sub-entries         |
| Paste            | Ctrl + V | None       | Pastes a copied entry into the current register |
