1. Currently
     - Cannot be opened unless recognized
     - Cannot be renamed unless recognized
     - Can be deleted only
     - When recognized user must name it before it gets moved to the recognized category
     
2. Updated Version
     - When unrecognized, will be placed under respective category.
     - User can open the register and view the contents even when recognized.
     - Contents of unrecognized register cannot be edited, such as rename Entry/Sub, delete Entry/Sub, add Entry/Sub, move Entry/Sub
     
     - A glass pane can be used to make all the components non-interactable.
     - When user tries to to click on components a pop-up requests user to recognize that register.
     - The search function will still work as normal inside an unrecognized register.
 3. When Recognized (Updated Version)
     - When user recognizes a register it will no longer ask to name that register.
     - The register will simply get moved to the recognized category and the program will allot it a random name that follows a pattern.
     - It will be named "Register" followed by 2 random uppercase letters and 1 random single digit number.
     - Eg- "Register AF2", "Register GI6", "Register NZ4", etc.
     - Once the Register has been moved into the Recognized category an in-line editing field will open allowing the user to rename it if they want.
     - Otherwise the user can rename it manually later as they wish.
