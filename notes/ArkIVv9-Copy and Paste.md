
## Copy
- Entry Block : An Entry and all it's respective sub-Entries will be referred to as an 'Entry Block'
- Users will be allowed to only copy Entries, this will also include all the sub-Entries inside it 
- Individual sub-Entries cannot be copied directly
- When an Entry block has been copied, a toast will indicate it was successful
- When User tries to copy a sub-Entry a toast will indicate that it is not allowed 
- The Entry block to be copied must be first selected by the user, and when it is the user may perform a 'copy'
- Trying to perform copy when no Entry has been selected - Nothing will happen 
- The Copy action can be performed through 'Shift+C' 
- When performing copy with an Entry already selected, wether the sub-Entries are collapsed/expanded will not matter

## Paste

- A user can paste any copied Entry-block in any register
- On pasting, the copied Entry block gets added to the current resgister user is in as a new Entry with sub-Entries
- User can paste an Entry block in the free state of the current register, i.e. there are no pop-ups, create sub-Entry/Edit ENtry fields, etc. that are blocking the screen 
- The users are prohibited from pasting any copied Entry blocks into any sort of input textfield in the App
