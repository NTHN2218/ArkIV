
1. Overview
    - Every Entry and sub-Entry will be numbered
    - The numbering will be placed above each checkbox that belongs to each Entry/sub-Entries
2. Numbering
    - It will be in plain numeral form
    - It will be numbered from 1-999
    - In a register, a maximum of 999 Entries only will be permitted.
    - In/under an Entry, a maximum of 999 sub-Entries only will be permitted. (Each sub-Entry can have up to 999 sub-Entries)
    - Users will be prohibited/stopped from exceeding these set limits.
    - If User places a .json in assets/data/. containing Entries/sub-Entries that exceed the set limit, the App will simply refuse to render beyond 999 in any of the two cases, but no data will be deleted or removed by the App to fit the data into the limit i.e. under no circumstances will the original data be deleted without user's consent. 
3. Numbering Appearance
    - It will be rendered above the respective checkbox of each Entry/sub-Entry
    - It will be a muted color, matching that of the color used by popular IDE's for line numbering.
    - Font: JetBrains Mono 
    - Font Size: 10
